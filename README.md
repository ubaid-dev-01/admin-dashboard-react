## Overview

A React + Vite admin dashboard for day-to-day business operations: sales, purchases, accounts, summary KPIs, and settings. Table-heavy UI with TanStack Table and React Hook Form workflows.

## Features

- Sales and purchases modules
- Accounts management
- Summary KPIs
- Settings
- Reusable table/UI kit

## Architecture

Client SPA with page-level modules under `src/pages` and shared UI under `src/components`.

## Tech stack

- React
- Vite
- TypeScript
- TanStack Table
- React Router
- Tailwind CSS
- React Hook Form

## Project structure

```text
admin-dashboard-react/
├── src/pages/

└── docs/
```

## Getting started

```bash
npm install
npm run dev
```
